# Splash page assets

- **three-phones.png** – Hero 3-phone mockup (also used for og-image.png).
- **adding-habit.png** / **editing-habits.png** – Poster frames for the “See it in action” videos.

To enable autoplay for the two flow videos, add these files (same names, `.mp4`):

- `adding-habit.mp4` – Screen recording: adding a habit and using the grid.
- `editing-habits.mp4` – Screen recording: editing habits and viewing analytics.

Keep files small (e.g. compress to web-friendly MP4). Until the MP4s are present, the poster images are shown.
